## Closeout

- root_cause: CPE's port (`cpe_ports::ArchiveProjection`, #452) had only its fake, so nothing could serve real archive facts to CPE. The Access Area's `sync`
  capability did not exist, and the on-disk format and parser for its committed projection were undecided (ARCH-MAP left both to DEV-7399).
- investigation: The format was decided in the PRD as an interim, DAO-shaped N-Quads snapshot written by `dao-lift` (dsp-incubator#411, pinned at
  1826d49f). Phase 1 first mapped it leniently ("check only what the port lists"); review showed that incomplete representations and several FORMAT.md
  "exactly one" rules were silently accepted. A read-only investigation found `dao-lift` refuses all of them, so a lenient reader only hides corruption.
  A DSP-API investigation confirmed that the value IRI changes across versions while `valueHasUUID` stays, which does not affect the interim node IRI
  (minted from the UUID), and that DSP-API does not enforce file-wide UUID uniqueness, which the format does (follow-up DEV-7455).
- solution: `sync-store` (areas/access/sync/store) implements `LiveArchiveProjection` over `areas/access/sync/data/0803.nq`, read per call with a strict
  `oxttl` parse. It refuses (`Unavailable`) every FORMAT.md violation on a served fact, omits only what FORMAT.md lets a reader omit, with one documented
  exception (an edge to an untyped value node), and runs `cpe_ports::contract::violations` on its own output before serving. The committed snapshot
  comes with PROVENANCE; ADR-0007 is amended, `areas/access/sync/CONTEXT.md` added, ARCH-MAP and the crate lists updated.
- prevention: 80+ synthetic tests (one per refused rule, each shown red before its check) plus fidelity tests that pin the committed file to literal
  facts of its dump and fail, not skip, when it is absent; a test that the PROVENANCE and `vocab.rs` pins agree; the run-time contract check as a last
  guard. A new invariant in `cpe-ports`' contract can take a project offline, which `contract.rs`, ARCH-MAP and `cpe/CONTEXT.md` now say.
