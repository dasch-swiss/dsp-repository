problem: >
  Incunabula cannot be served from dsp-repository until CPE's store, its page assembly and a router are
  there, and something builds the store from the archive projection at run time. The prototype in
  dsp-incubator holds them (`cpe-store`, `cpe-store-build`, `cpe-web`, `cpe/bin`), builds the store with a
  command-line tool whose output is committed, and has no base path, so a mount under `/cpe` alone would
  serve pages whose links, redirects and cookies leave the mount. This plan moves the three crates, adds
  the host crate `cpe-server`, activates Incunabula from `sync`'s port at process start, gives CPE a
  configured base and mounts it in `access-server` (DEV-7465, DEV-7438, the last step of DEV-7400).
