## Closeout
- root_cause: The editor's shared widgets were built feature by feature with no single owner for cross-cutting display rules: each status source (flash, locked, approved, round) rendered its own box; entity text was formatted at each call site from whatever id or name was at hand; the "Add another" input kept a stable id across morphs, so Datastar patched it in place and kept the typed text; the review queue and the drafts list filtered on different keys; the shared button styles inherited hover colours that failed AA and used `:enabled`, which never matches `<a class="btn">`.
- investigation: Seven stage-test issues triaged into eight phases, each with a seven-reviewer checkpoint; a final full-diff review found the `enabled:hover:` regression on link-buttons, a published-first vs proposal-first naming split between the section and entity pages, and two deviations the owner accepted (a newer ChangesRequested/Rejected round beats the awaited approval; the add-box id changes on every response that posted add-box text). Section 01's 320×800 run found the sticky status region covering the invalid field after a refused submit.
- solution: One persistent status box by precedence with audience-specific wording and a release-on-demand wait string; `entity::entity_label` with an explicit `Precedence` as the one owner of entity display text; an add-box id carrying a per-response token, a renamed checkbox group and focus kept on the replacement; one "Drafts in progress" predicate; `not-disabled:hover:` button states measured at AA; `text_field().label_hidden()` for row labels; read-only legal info and `Section::has_editable_field`; a status region sticky and capped only at `md` and up, with scroll margin on fields.
- prevention: `depositor_vocabulary.rs` rejects `person-N`, `organization-N` and `EDITOR_*` in depositor-visible text, including a live proposals box and its findings; handler tests pin the box precedence; Playwright pins the add box clearing and keeping focus in both passes, and the status region not covering a field at 320 and 1280 wide; the editor and DPE axe suites cover the button states; the editor CLAUDE.md and ARCH-MAP name the naming API and its id exception.
